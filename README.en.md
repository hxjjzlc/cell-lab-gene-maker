A zero-dependency `.genome` toolkit for the mobile game *Cell Lab* (细胞实验室). Converts recipe JSON to the game's binary genome format and back, plus a growth tree renderer and a structural simulator. The core is a single JS file that runs on Node, in a browser, or inside an app's embedded JS engine. No zlib, no Buffer, no npm.

## What it does

- Compile recipe JSON into a `.genome` the game accepts
- Parse real genome files into structured parameters (JSON)
- Structural check: segment count, version, out-of-range child modes, duplicate mode identity
- Growth tree: what each mode grows into, and where the chain breaks
- Structural simulation: with unlimited light and food, how many connected bodies form, what each is made of, which flagella die at birth

## Two format generations

| Gen | Container | Version | Segment | Notes |
|---|---|---|---|---|
| Legacy | bare Java stream (starts `AC ED 00 05`) | v95 / v3055 | 315 / 331 bytes | original Cell Lab; v95 = 40 slots, v3055 = 127 slots |
| Modern | ZIP container (`PK`, holds `save.bin` + `thumbnail.png`) | v3145 / v3169 | 1125 / 1212 bytes | Cell Lab: Macro; segment count = actual mode count |

A given game build accepts exactly one container type. Modern builds reject the legacy stream with "unrecognized file"; legacy builds cannot read the ZIP. That mismatch is the most common import failure.

## Quick start

Node only, no dependencies.

```bash
node cli.js types                       # cell type table
node cli.js presets                     # built-in recipes
node cli.js make presets/swimmer.json -o swimmer.genome
node cli.js read swimmer.genome         # auto-detects generation
node cli.js verify swimmer.genome       # structural check
node cli.js tree presets/swimmer.json   # growth tree
node cli.js sim  presets/swimmer.json --max-cells 150
```

Pick the generation on the command line or in the recipe:

```bash
node cli.js make recipe.json -o out.genome --format modern   # Macro
node cli.js make recipe.json -o out.genome                   # legacy bare stream
```

If you have a real export at hand, pass `--template` to inherit its version, segment length and tail structure (plus the thumbnail for modern), overriding only the fields your recipe names:

```bash
node cli.js make recipe.json -o out.genome --template sample.genome
```

## Recipe

```json
{
  "format": "modern",
  "name": "simple swimmer",
  "modes": [
    { "type": "phagocyte",    "color": [0.75,0.9,0.35], "splitMass": 2.5, "children": [1,2], "makeAdhesin": true },
    { "type": "flagellocyte", "color": [0.95,0.55,0.2], "splitMass": 3.6, "swimForce": 0.6, "children": [1,2] }
  ]
}
```

Fields: `type` `color` `splitMass` `splitRatio` `splitAngle` `child1Angle` `child2Angle` `children` `makeAdhesin` `child1KeepAdhesin` `child2KeepAdhesin` `priority` `adhesinStiffness` `maxConnections`, plus per-type `swimForce` `density` `muscle*` `stemThreshold*` `secreteType` `smell*` `signals` `virusFrom/virusTo` `values`.

Full field tables, the byte-level layout of both generations, and per-type mechanics live in `SKILL.md` and `references/classic-mechanics.md`.

## Three things that bite

- Normal cells cap at 3.6 ng, lipocytes at 21.6 ng. The split-mass slider cannot go past 3.672; writing 3.672 means "never divides".
- Functional cells (neurocyte, senseocyte, stereocyte, flagellocyte, glueocyte, keratinocyte) cannot feed. Set them to 3.672. A low threshold makes them retry forever and burn energy on the way.
- In the modern format, one byte at segment offset 1174 is the mode identity and must be globally unique. A straight recipe build duplicates it, and the failure mode on a real device is "imports fine, crashes on entering the dish". Clone segments from a real export and write unique identities.

## Known limits

- In the modern format, the ten per-cell-type parameter blocks after byte 511 are preserved verbatim; their semantics are not parsed.
- The simulation is geometric. No thrust, no fluid, no soft-body deformation, no starvation. It answers connectivity and composition only.
- Macro's added cell types (gangliocyte, luxocyte, cnidocyte, ...) are not yet mapped to their in-game numbering; they read back as "type N (Macro)".
